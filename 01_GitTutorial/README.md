# Introduction to Git

Takehome message: **Use git**

## Before you start

1. Create a GitHub account (use your **@umich.edu** address) and turn on two-factor authentication.
2. Install [GitHub Desktop](https://desktop.github.com/) (or a client of your choice) and sign in.
3. Send your GitHub username to the instructor.

## Assignment

You will not be able to push directly to `beards-lab/Phys520` unless you have been
added as a collaborator, so the default route is **fork first**:

1. **Fork** https://github.com/beards-lab/Phys520 to your own account
   (GitHub web UI: the *Fork* button, top right).
2. **Clone your fork** to your computer
   (GitHub Desktop: *File ▸ Clone repository*, pick your fork).
3. Create `initials_your-nick-name.md` in the `01_GitTutorial` folder
   - e.g. `FJ_jez.md`
4. Write down what you
   1. like about GitHub
   2. dislike about GitHub
   3. at least one question
5. **Commit** it, with a message that says what you did.
6. **Push** to your fork.
7. Open a **pull request** from your fork back to `beards-lab/Phys520`.

*Already a collaborator on `beards-lab/Phys520`?* Then you may clone it directly,
push a branch named after yourself, and open the pull request from that branch —
please do not commit straight to `main`.

## Questions

Your question from step 4 gets answered in the follow-up session. Ask something
